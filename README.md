# HideAuto

**HideAuto** is a desktop app for visual browser automation. Build automation flows on a drag‑and‑drop canvas, then run them across hundreds of browser profiles — manually or on a schedule.

## What you can do

- **Design visually** — assemble your automation step by step on a node‑based canvas. No coding required.
- **Run at scale** — execute the same flow across many browser profiles in parallel, each isolated with its own fingerprint.
- **Schedule & monitor** — set flows to run on a schedule and follow progress in real time with per‑step logs and status.
- **Stay in control** — test before production, reversible actions, and clear success/error states for every run.

## Download & install

Grab the latest build for your platform from the [**Releases**](../../releases) page:

- **Windows** — `.exe` installer
- **macOS** — `.dmg`
- **Linux** — `AppImage`

Download, run the installer, and launch **HideAuto**. The app updates itself automatically when a new version is published.
